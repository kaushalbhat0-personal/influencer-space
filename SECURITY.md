# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in CreatorStore, please report it privately.

**Do not report security vulnerabilities through public GitHub issues.**

Instead, send a description of the issue to **support@influencerspace.in**.

Please include:

- Type of issue
- Steps to reproduce
- Potential impact
- Suggested fix (if applicable)

You should receive a response within 48 hours. If the issue is confirmed, a fix will be released as soon as possible.

## Scope

The following are in scope:

- Authentication bypass
- Authorization bypass
- Data exposure
- Remote code execution
- SQL injection
- Cross-site scripting
- CSRF

## Out of Scope

- Rate limiting bypass (unless data exfiltration is involved)
- Missing security headers
- SSL/TLS configuration
- Social engineering
- Physical access attacks

## Supported Versions

Only the latest stable release receives security updates.
