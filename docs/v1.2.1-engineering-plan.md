# v1.2.1 Engineering Plan - ClientAssignment Migration

> **Status:** Planned
> **Target:** v1.2.1 release

---

## Objective

Migrate ClientAssignment data from Setting JSON to a dedicated database table.

---

## Architecture

WorkspaceMember -> ClientAssignment -> Tenant

## Schema Fields

- workspaceId (FK -> Workspace)
- tenantId (FK -> Tenant)
- userId (FK -> User)
- role (string: account_manager, designer, developer, content_editor, support)
- assignedAt (DateTime)

Unique constraint: [workspaceId, tenantId, userId]

## Migration Steps

1. Add ClientAssignment model to prisma/schema.prisma
2. Run prisma migrate
3. Backfill existing data from Setting table
4. Update AssignmentService to use new table
5. Remove Setting JSON storage

## Backward Compatibility

- Reads try ClientAssignment table first
- Fall back to Setting JSON if not found
- Writes go to both during transition

## Rollback

Keep Setting JSON data until migration is confirmed.
